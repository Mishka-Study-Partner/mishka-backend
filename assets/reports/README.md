# Your Report PDF assets

Copy from the Flutter app for best visual parity:

| File | Flutter path |
|------|----------------|
| `app-logo.png` | `assets/images/app-logo.png` |
| `streak_today.png` | `assets/images/streak_today.png` |

**Fonts:** Pridi is loaded from Google Fonts in the HTML template. To embed offline copies, add `Pridi-*.ttf` here and update `yourReportHtmlRenderer.js`.

If assets are missing, the PDF still renders (text logo + SVG mascot placeholder).
